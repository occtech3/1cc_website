=== One Christian Church ===
Requires at least: 6.0
Tested up to: 6.8
Requires PHP: 7.4
License: GPLv2 or later

Design preview theme for One Christian Church, Greenwood, Indiana.

== Installing ==

1. In WordPress, go to Appearance > Themes > Add New Theme > Upload Theme.
2. Choose one-christian-church.zip, click Install Now, then Activate.
3. Activation creates the pages (Home, Plan a Visit, About, Ministries, Events,
   Watch & Listen, Give, Contact) if they don't exist, and sets Home as the front page.
   Each page uses its matching template file, so the page bodies can stay empty.

== Customizing ==

* Logo: Appearance > Customize > Site Identity > Logo.
* Videos: Appearance > Customize > Background videos. Paste an MP4 URL per slot.
  The placeholders are Mixkit clips under the Mixkit Stock Video Free License,
  loaded from Mixkit's servers.
* Design preview note: untick it in the same Customizer section.

Page text lives in the page-*.php and front-page.php templates. Forms are mock-ups;
swap in a form plugin (WPForms, Fluent Forms or Gravity Forms) for the real build.
