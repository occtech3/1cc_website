One Christian Church: website design preview
============================================

Open index.html in a web browser (double-click it). Everything runs from this folder.
An internet connection is needed for the fonts and the map.

To share it online without a server, drag this folder onto https://app.netlify.com/drop,
or upload it to any web host or GitHub Pages.

Background videos go in assets/video/ (see the README there for the file names and where to
download each clip). Until they are added, the animated colour background shows instead.
Forms are mock-ups and don't send anything.
